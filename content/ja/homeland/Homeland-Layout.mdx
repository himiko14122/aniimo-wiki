## Homeland Grid と資源Logicの読み方

装飾を1つ配置する前に、あなた自身はGridを理解する必要があります。Aniimo homelandは campsite タイルに停められた個人RVに位置し、配置するすべての Object は freeform 座標ではなく grid cells で測定される定義された Footprint を消費します。Creature pen、crop plot、crafting station、装飾的 Anchor はすべて同じ座標系を共有します。つまり、thoughtful な Aniimo homeland layout は、散在するアプローチよりも、同じタイル数に劇的に多くの productive object を詰め込むことができます。

### Grid Cell が実際にどう機能するか

homeland grid は modular pattern に従い、隣接する object は edge や corner を共有する場合に bonus を chain できることがあります。例えば、water feature の隣に配置された crop plot は、播種したものの growth tick を加速し、feeding trough に隣接した creature pen は、その pen から収穫した material の daily yield を上げます。これらの adjacency bonus は、 **最高の Aniimo homeland layout** が単に object を詰め込むことではなく、意図的な neighbor chain を engineering することである中核的な理由です。

| Object Type | Base Footprint | Adjacency Synergy | Yield Impact |
|-------------|---------------|-------------------|--------------|
| Crop Plot | 2x2 cells | Water feature on any edge | Growth speed +15% |
| Creature Pen | 3x3 cells | Feeding trough on edge | Daily harvest +20% |
| Crafting Station | 2x2 cells | Storage chest on edge | Craft speed +10% |
| Decorative Anchor | 1x1 cell | None (cosmetic only) | Visit rating +1 |

decorative anchor は機械的に何とも chain しないことに注意してください。これが、空いたスペースを埋めるためにそれらを盲目的に散布することが、プレイヤーが早い段階で犯す最も一般的な mistake の1つである理由です。それらは social 機能(他の Pathfinder があなたの campsite にどれくらいの頻度で訪れるかを高める)を果たしますが、生産的な object と同じ grid real estate を cost します。

### Resource Clustering の原則

最も強力な layout は、 category ごとではなく destination ごとに resource を cluster 化します。crop plot をその出力を消費する crafting station の隣に置き、storage chest をそれらの crafting station に隣接して配置します。この3方向 chain は、RVのドアからの1回の walk で、キャンプを横切ることなく seeding、crafting、inventory management をカバーできることを意味します。公式[Aniimo Discord](https://discord.com/invite/aniimo)でのコミュニティ Testing は、この種の linear flow が Farming cycle ごとに約30秒を短縮することを示唆しており、これは完全な play session 全体で compound します。

## フェーズ1 Unlocks と最初に Build できる Homeland

すべての Pathfinder は小さな plot と少数の Object タイプから始まりますが、Aniimo homeland unlocks tree はあなたの canvas を distinct な phase で拡張します。最初に push すべき phase を知ることで、あなたの Aniimo homeland customization オプションが隣人よりもどれだけ早く outpace するかが決まります。

### Tier 1: 開始時の Plot

初期の homeland には fixed な RV位置、2つの crop plot、1つの creature pen、1つの storage chest が含まれています。これは restrictive に見えますが、実際には完全な adjacency system を示し、どの resource chain が自然に感じられるかを test するために十分です。多くの veteran な player は、この starter phase を deliberate に bad な layout で experiment するために使用し、長い walk や missed bonus の friction を感じた後、より大きな unlock が land した時に course-correct することを推奨しています。

| Starter Object | Function | Upgrade Path |
|----------------|----------|--------------|
| RV (fixed) | Fast travel anchor + social hub | Cannot be moved |
| 2x Crop Plot | Seed and harvest | Expand to 3x3 at Homestead Level 3 |
| 1x Creature Pen | House assigned Aniimo | Expand to 4x4 at Homestead Level 5 |
| 1x Storage Chest | Hold raw materials | More chests unlock per level |

### Tier 2: Expansion Unlocks

Homestead Level 3で、Aniimo homeland unlocks の2番目の Tier が kicks in し、crafting station、追加の crop row、feeding trough などの utility object の最初の batch を追加します。ここでほとんどの player は、 Tier 1 で確立された adjacency chain を保存する代わりに、新しい object を収まる場所に配置する mistake を犯します。disciplined なアプローチは、配置する前に grid の Zone 全体を新しい Object category として mental に reserve し、adjacency bonus edge を dead corner に散らけるのではなく、既存の productive object に route することです。

### Tier 3: Premium Slots と Visitor Appeal

Homestead Level 7は premium decorative tier と visitor rating system を unlock します。visitor appeal が tracked metric になると、あなたの Aniimo homeland layout の choice が daily に何人の visitor が到着するかに影響し始め、visitor は material economy に feed back する gift drop をもたらします。この stage での最良の layout は、機械的な yield zone と RVドア近くの small で dense な social zone のバランスを取ります。なぜなら、visitor は RVで spawn し、あなたの camp が滞在する価値があるかを決定する前に限られた距離のみ walk するからです。

## 実践的な Aniimo Homeland Customization Pattern

grid と unlock phase を理解したら、次の step はあなたの playstyle に match する layout pattern を選択することです。crafting、raw material Farming、 social interaction のいずれを優先するかによって optimal な pattern は異なるため、誰にとっても single な **最高の Aniimo homeland layout** は存在しません。

### Linear Production Strip

solo player にとって最も efficient な pattern は、RVドアから crop plot、crafting station、storage を通って直線で走る linear production strip です。 advantage は、すべての productive object に backtracking せずに reach でき、grid space があれば chain 全体を RVの反対側に mirror できることです。[Aniimo solo play guide](/ja/guides/solo-play-guide/)を実行する player は、travel friction を minimize し、毎分の crafting throughput を maximize するため、この pattern を favor する傾向があります。

| Zone | Object Stack | Adjacency Chain |
|------|--------------|-----------------|
| Zone A (RV) | RV + welcome chest | Visitor spawn point |
| Zone B (Farming) | 4x crop plots + water feature | Growth speed +15% |
| Zone C (Crafting) | 2x crafting stations + 2x storage | Craft speed +10% |
| Zone D (Creature) | Creature pen + feeding trough | Daily harvest +20% |

### Hub-and-Spoke Pattern

co-op player と heavy な socializer は通常、RVが productive zone の円形 arrangement の center に座る hub-and-spoke pattern を prefer します。pattern は corner でいくつかの adjacency edge が失われるため、object あたりではわずかに less efficient ですが、すべての productive zone が RVから visible であり、すべての zone が central な spawn からの short な walk であるため、 visitor flow を劇的に改善します。co-op system を使用して[他の Homeland を visit する](/ja/homeland/visit-other-homelands/)と、最も popular な camp がほぼ常にこの pattern の variation を使用していることに気付くでしょう。

### Hybrid Split

hybrid split は、grid を2つの半分に分割します。1つの半分は solo yield 用の tightly packed な linear production strip で、もう1つの半分は bench、 light 、少数の premium cosmetic anchor を備えた decorative な social zone です。これは、play 数週間後にほとんどの veteran な Pathfinder が settle on する pattern です。なぜなら、daily visitor traffic を drive する social rating を sacrifice することなく、自分の Farming loop を optimize できるからです。trade-off は、純粋な linear strip よりも total な productive object が少なくなることです。そのため、hybrid は split に afford できるだけの grid space を unlock した後にのみ make sense します。

## Aniimo Homeland Upgrades と機能する優先順位

間違った order で upgrade currency を spending することは、homestead progress を stall する最速の方法です。Aniimo homeland upgrades tree はいくつかの方向に branch し、すべての branch が resource ごとに equal な return をもたらすわけではありません。[Aniimo Steam Community Hub](https://steamcommunity.com/app/4126040)を通じて surfaced な thread に基づく community-tested な priority order は、おおよそ次のとおりです。

### Tier 1 Priorities(常に最初に Push)

すべての Pathfinder が chase すべき最初の3つの upgrade は、 **Homestead Level cap raise**、**Storage Chest expansion**、**Crop Plot efficiency** node です。これら3つは、より頻繁に log in したり layout を変更したりすることを require せずに passive yield を直接 multiply します。特に Storage は、 chest がいっぱいになると、surplus harvest が daily yield に対して counting を停止し、income を silently cap するため、hidden bottleneck です。

| Upgrade Node | Cost Tier | Yield Multiplier | Why First |
|--------------|-----------|------------------|-----------|
| Homestead Level Cap | Medium | Unlocks next tier objects | Required for everything else |
| Storage Chest Expansion | Low | +20 chest slots | Prevents yield cap from full inventory |
| Crop Plot Efficiency | Low | Growth speed +25% | Doubles effective harvest rate |

### Tier 2 Priorities( Tier 1 が settle した後に Push)

Tier 1 node が max になったら、次に best な return は **Creature Pen capacity**、**Crafting Station speed**、**Visitor Appeal** node から得られます。Creature pen capacity は、pen から収穫される material が crop yield よりも rare であるため、しばしば underrated ですが、 end-game equipment を gate する higher-tier crafting recipe に feed します。Visitor Appeal は3つの中で slowest-burn な investment ですが、compound します。より多くの visitor はより多くの gift を意味し、それはより多くの rare material を意味し、それはより多くの crafting を意味します。

### Tier 3 Priorities(Endgame Optimization)

Tier 3 upgrade は、**最高の Aniimo homeland layout** の discussion が spicy になる場所です。なぜなら、ここでの node は主に cosmetic adjacency multiplier と premium crafting unlock であるためです。これらは最後に push してください。なぜなら、基本的な yield infrastructure がすでに humming になっている場合にのみ matter するためです。例としては、**Premium Crafting Station**、**Advanced Feeding Trough**、**Visitor Gift Amplifier** node などがあり、すべて meaningful な boost をもたらしますが、すでに mature な layout を running していることを assume しています。

## Creature Placement と Aniimo 固有の Tips

homeland 内の Creature placement は、pen に assign する各 Aniimo が独自の element と独自の material type を yield するため、 object placement とは別の sub-system です。pen 内に assign した creature をどのように配置するかが、 daily yield と他の player が visit した際に見る social rating の両方に影響します。

### Pen Slot への Element の Matching

ほとんどの pen には4～6個の slot があり、complementary な element を持つ creature が隣接 slot に配置されると、small な synergy bonus が生まれます。隣接 slot にある同じ element の creature 2体は bonus を提供しませんが、opposing element の creature 2体は minor な debuff をもたらします。 best な practice は、pen grid 全体で element type を交互にし、任意の1つの element を2つ以上まとめて stack しないことです。[creature elements reference](/ja/creatures/common-creatures/)は、どの combination が complementary として qualify するかの完全な breakdown を提供します。

### Social Visibility の Tricks

visitor が spawn した時点で RVから visible な creature は、crafting station の後ろに hidden された creature よりも、visitor appeal score に多く contribute します。hybrid split layout を running している場合は、showpiece creature を production zone ではなく social zone に配置することで、daily visitor の measurable な boost を得ることができます。これは cosmetic に聞こえるが、 gift drop を通じて material economy に feed back する Aniimo homeland tips の1つです。

### Pen Expansion の Timing

新しい slot を fill する準備ができている compatible な creature を少なくとも4体持った後にのみ pen を Expand してください。なぜなら、半分の empty な large pen は、満杯の small pen よりも cell あたりの yield が少ないためです。closed beta での Community Testing は、underused な pen slot が pen の daily output の約12～15%を cost することを示唆しているため、upgrade math はすぐに space を fill できる場合にのみ有利に機能します。

## 良い Layout でさえ stall する一般的な Mistake

強力な Aniimo homeland layout が place されていても、いくつかの recurring な mistake が yield curve を静かに sabotage する可能性があります。これらは player report と dev Q&A thread で最も頻繁に表示される issue であり、何を探すべきかを知っていれば簡単に avoid できます。

### Mistake 1: 生産の前に装飾する

新しい player は、 cosmetic object が visual に rewarding であるため、homestead play の最初の数時間を decorating に spending する傾向がありますが、productive cell に配置されたすべての decorative anchor は missed yield opportunity です。rule of thumb は、最初にすべての productive cell を fill し、次に cosmetic を残った gap に layer することです。crop plot が配置できる場所に bench を配置したいことに気付いた場合、production zone が完全に saturate されるまで crop plot が優先されます。

### Mistake 2: 痛むまで Storage を無視する

Storage は、failure mode がすでに yield を失うまで invisible であるため、 silent killer です。 chest がいっぱいになると、追加の harvest は overflow に disappear し、game は warning を flash しません。すべての play session の最後に chest fill level を確認し、定期的に capacity の80%を超えたらすぐに storage expansion node を push してください。

### Mistake 3: Trough なしで Creature Pen を配置する

adjacent な feeding trough がない creature pen は daily yield の20%を失います。これは system 全体の中で最大の single-object adjacency bonus です。trough 自体は cheap かつ small であるため、cost-benefit math はほぼ常に、pen を配置した瞬間にそれを追加することを favor します。逆の logic も同様に適用されます。少なくとも1つの edge に pen がない feeding trough を配置しないでください。なぜなら、isolated な trough は bonus をもたらさないからです。

## Late-Game Layout のための Advanced Tricks

homestead が unlock tier を通じて成熟し、基本的な yield が stable になると、いくつかの advanced trick が追加の resource を spending せずに output をさらに push できます。これらは、good な Aniimo homeland layout と truly great な Aniimo homeland layout を区別する optimization です。

### Diagonal Adjacency Exploit

system の一部の object は、shared edge だけでなく diagonal corner 全体で bonus を chain します。例えば、water feature の diagonal corner に配置された crop plot は、依然として partial な growth bonus を受け取り、2つのそのような diagonal chain を stack すると、single な edge adjacency よりも高い yield をもたらす可能性があります。math は fiddly ですが、何かを配置する前に grid を paper に map する player は、edge-only chaining よりも 5～8%の yield improvement を consistently に report しています。

### Visitor Path の Engineering

RV spawn point と最も visual に striking な object の間の path は、visitor があなたの camp でどう behave するかを shape します。RVと production zone の間の natural な walking path に沿って showpiece creature pen または rarest な decoration を配置すると、visitor があなたの camp を highly に rate し、gift drop bonus を trigger する可能性が高くなります。これは game mechanic ではなく layout-level の psychology ですが、effect は real であり、visitor count log で measurable です。

### Seasonal Layout の Rotation

homeland system には、visitor に最も popular な object と creature を subtle に shift する seasonal theme rotation が含まれています。現在の season に match するように social zone decor を rotation し、pen の visible な slot に座る creature を rotation することで、visitor rating を elevated に保ち、returning visitor を engaged に保ちます。これは implementation に almost nothing を cost しないが、play の1年全体で pay off する Aniimo homeland tips の1つです。

## よくある質問

**新しい player のための single な最高の Aniimo homeland layout は何ですか?**

linear production strip は、新しい player のための最も forgiving な pattern です。set up に advanced な adjacency math を require せず、unlock する grid space が増えるにつれて clean に scale するためです。RVから straight line に配置された crop plot と1つの creature pen から始め、最初の日に feeding trough と water feature を追加し、新しい object が unlock するにつれて sideways に Expand します。

**homeland のために より多くの grid space を unlock するにはどうすればよいですか?**

Grid space は Homestead Level が上がるにつれて automatically に expand します。これは daily objective を完了し、新しい object を配置し、visitor の gift を受け入れることによって drive されます。Homestead Level を push する最速の方法は、unlock した日に、利用可能なすべての cell を productive object で fill することです。 placement event は level XP に対して count されますが、 empty cell は count されないためです。

**homeland を customizing する際、crop と creature のどちらに focus すべきですか?**

Crop は growth cycle が short であるため、より速い feedback をもたらし、early-game learning により適しています。 crop zone が stable で storage expansion が place に入ったら、pen material が mid-game progression を gate する higher-tier crafting recipe に feed するため、investment を creature pen に shift してください。

**visitor appeal rating を上げるにはどうすればよいですか?**

Visitor appeal は、decoration density、RVからの creature visibility、seasonal theme matching の mix によって drive されます。rating を上げる最も cheap な方法は、RV近くの social zone に1体または2体の showpiece creature を配置し、現在の season に match するように cosmetic anchor を rotation して、 returning visitor が fresh な何かを見れるようにすることです。

**set up した後、homeland layout 全体を re-arrange できますか?**

はい、layout system は fully modular であり、各 move の後に short な placement cooldown があるものの、cost なしで任意の object をつかみ取って reposition できます。これにより、unlock tier が Expand するにつれて different な Aniimo homeland customization pattern を experiment することが easy になり、多くの veteran は、新しい adjacency option を absorb するために5 Homestead Level ごとに完全な layout review を推奨しています。
